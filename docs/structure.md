# Project structure

## Directories

```
finanpy
├── agents/            # AI agents of the development team (index in agents/README.md)
├── accounts/          # bank accounts
├── categories/        # transaction categories
├── core/              # global project settings
│   ├── settings.py
│   ├── urls.py
│   ├── asgi.py
│   └── wsgi.py
├── profiles/          # user profiles
├── transactions/      # income and expenses
├── users/             # system user
├── docs/              # this documentation
├── templates/         # project templates (base, home, dashboard, one folder per app)
│   └── components/    # partials
├── manage.py
├── README.md
├── requirements.txt
├── ruff.toml          # PEP 8 lint configuration (ruff)
└── PRD.md             # product requirements document
```

Each app follows the default structure generated by `startapp`:

```
<app>/
├── migrations/
├── admin.py
├── apps.py
├── models.py
├── tests.py
└── views.py
```

Additional files planned in the PRD for each app, created as needed: `forms.py`, `urls.py` and, when there are signals, `signals.py`.

## Current settings (`core/settings.py`)

| Setting | Value |
|---|---|
| `INSTALLED_APPS` | native Django apps + the project apps registered by their `AppConfig` (`'accounts.apps.AccountsConfig'` and so on), each with a Portuguese `verbose_name` |
| `DATABASES` | SQLite at `BASE_DIR / 'db.sqlite3'` |
| `TEMPLATES['DIRS']` | `[BASE_DIR / 'templates']` |
| `LANGUAGE_CODE` | `'pt-br'` |
| `LANGUAGES` | `pt-br` (default) and `en-us` |
| `TIME_ZONE` | `'America/Sao_Paulo'` |
| `USE_I18N` / `USE_TZ` | `True` |
| `USE_THOUSAND_SEPARATOR` | `True` (pt-BR money as `1.234,56`) |
| `AUTH_PASSWORD_VALIDATORS` | native Django validators |
| `MAILERS` | console backend |
| `DEBUG` | `True` |

## URLs (`core/urls.py`)

| URL | Name | Target |
|---|---|---|
| `/` | `home` | `HomeView` (public) |
| `dashboard/` | `dashboard` | `DashboardView` |
| `signup/`, `login/`, `logout/` | `signup`, `login`, `logout` | `users.urls` |
| `profile/` | `profile` | `profiles.urls` |
| `accounts/`, `accounts/new/`, `accounts/<pk>/edit/`, `accounts/<pk>/delete/` | `account_list`, `account_create`, `account_update`, `account_delete` | `accounts.urls` |
| `categories/` (same pattern) | `category_list`, `category_create`, `category_update`, `category_delete` | `categories.urls` |
| `transactions/` (same pattern; list accepts `?month=AAAA-MM&type=income\|expense&page=N`) | `transaction_list`, `transaction_create`, `transaction_update`, `transaction_delete` | `transactions.urls` |
| `admin/` | — | Django Admin |

Each app's URLs must live in `<app>/urls.py` and be included in `core/urls.py`.
